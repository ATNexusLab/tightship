# tightship

A workflow for AI coding agents, packaged as a plugin: the contract the agent works by, the skills and
commands that carry a feature from requirement to pull request, a read-only verifier, a memory vault shared
across sessions and machines, and a status line.

It ships for Claude Code first. Cursor, Antigravity CLI, and Codex follow.

## Install

Claude Code 2.1.295 or later. The [install guide](docs/install/claude-code/README.md) covers installation, the
companion plugins, the options, update, uninstall, and the migration from the pre-plugin install.
