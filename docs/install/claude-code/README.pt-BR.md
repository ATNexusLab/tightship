# Instale o tightship no Claude Code

[English](README.md) · Português

Como instalar, configurar, atualizar e remover o plugin tightship no Claude Code, e como passar para ele a
partir da instalação anterior ao plugin.

## Antes de começar

- Claude Code 2.1.295 ou posterior. Confira com `claude --version`. Versões mais antigas não têm suporte, e
  nada no plugin confere a versão por você.
- No Windows, o Git for Windows: os hooks do plugin rodam no `sh` dele.
- Git, quando a memória está ligada, já que o vault é um repositório git.
