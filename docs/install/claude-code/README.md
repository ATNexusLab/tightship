# Install tightship in Claude Code

How to install, configure, update, and remove the tightship plugin in Claude Code, and how to move to it from
the pre-plugin install.

## Before you start

- Claude Code 2.1.295 or later. Check with `claude --version`. Older versions are not supported, and
  nothing in the plugin checks the version for you.
- On Windows, Git for Windows: the plugin's hooks run through its `sh`.
- Git, when memory is on, since the vault is a git repository.
