# Install tightship in Antigravity CLI

English · [Português](README.pt-BR.md)

How to install, configure, update, and remove the tightship plugin in Antigravity CLI, and how to move to it
from loose rules and skills.

## Before you start

- Antigravity CLI 1.4.0 or later. Check with `agy --version`.
- On Windows, PowerShell or Git Bash for running hooks and the installer.
- Git, when memory is on, since the vault is a git repository.
