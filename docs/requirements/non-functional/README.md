# Non-functional requirements

One file per ISO/IEC 25010:2023 characteristic the product constrains.

| Characteristic | Code | File |
| --- | --- | --- |
| Flexibility | `FLEX` | [flexibility.md](flexibility.md) |
| Compatibility | `COMP` | [compatibility.md](compatibility.md) |
| Security | `SEC` | [security.md](security.md) |
| Maintainability | `MNT` | [maintainability.md](maintainability.md) |
| Reliability | `REL` | [reliability.md](reliability.md) |
| Performance efficiency | `PERF` | [performance.md](performance.md) |

Functional suitability, interaction capability, and safety have no requirement of their own: the
functional requirements cover the first, and the product has no screen and controls no physical process.
