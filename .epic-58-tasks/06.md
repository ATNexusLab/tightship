# Options file and tightship options subcommands

## Context

Business rule(s) 5 — spec: `docs/specs/cursor-plugin/ship-for-cursor.md`

## Scope

`tightship/src/options/`, hook guards reading options.json, manifest `variables`.

## Acceptance criterion

Scenarios 4, 8, 9, 10

### Scenario 9 — Set an option (FR-INS-04.1, happy path)

```gherkin
Given options.json does not exist
When the adopter runs tightship options set memory false
Then stdout is "Set memory to false."
And options.json holds "memory": false
```

### Scenario 10 — Unknown option (exception)

```gherkin
When the adopter runs tightship options set not_an_option true
Then stderr is "error: unknown option \"not_an_option\""
And the exit code is 1
```

## Possible impacts

Data model options.md already documents the file.

## How to test

1. cargo test tightship options
2. Run subcommands against a temp HOME
